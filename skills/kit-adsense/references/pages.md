# 필수 페이지 내용

Blogger 는 "페이지" 기능(고정 페이지, `/p/<slug>.html`)으로 만들고 상단 메뉴에 연결. 일반 사이트는 고정 URL + 푸터 링크.
아래는 항목 목록이며 문구 템플릿이 아님. 사이트 실제 정보로 작성.

## about_page (소개)

- 운영자: 이름 또는 필명, 관련 경험 · 관점
- 다루는 주제와 다루지 않는 주제
- 작성 방식: 자료 출처 원칙, 갱신 원칙
- 자동화 · AI 사용 여부와 사람의 검토 범위 (ai_disclosure)

## contact_page (문의)

- 이메일 또는 문의 양식. 응답 범위 (예: 개별 투자 상담 불가)

## privacy_page (개인정보처리방침)

- 수집 항목: 방문 로그 · 쿠키 · 댓글 · 문의 정보
- Google 등 제3자 광고 업체가 쿠키로 이전 방문 기반 광고를 게재한다는 고지
- 맞춤 광고 해제 방법: Google 광고 설정 링크
- 분석 도구 사용 시 명시 (Google Analytics 등)
- 문의처 · 시행일
- 국가별 법(한국 개인정보 보호법, GDPR 등)은 대상 독자 기준으로 확인

## disclaimer_page (면책, YMYL 주제)

- 금융: 정보 제공 목적, 투자 권유 아님, 투자 판단 · 손실 책임은 본인, 수치는 작성 시점 기준
- 건강: 의학적 조언 대체 아님
- 제휴 링크 사용 시 고지
- 한국 금융 주제: 대가를 받는 1:1 투자 조언 · 유료 리딩은 유사투자자문업 신고 대상. 무료 공개 분석은 "분석" 표현 유지, 매수 · 매도 지시형 문장 지양

## 공통

- 각 페이지는 실제 내용이 있어야 함. "준비 중" 페이지는 navigation_clean fail
- 글 하단 또는 사이드바에서 소개 · 면책 페이지로 연결
