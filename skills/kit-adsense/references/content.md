# 글 소재 · 맥락 · 블로그 구성

AdSense 승인과 수익은 검색 유입 품질에 좌우. 기준은 Google Search Central 의 유용한 콘텐츠 가이드 (사람 우선, E-E-A-T).

## 소재 고르기

- 검색 수요가 있는 질문형 주제. 일반어보다 롱테일 ("ISA" → "2026 청년형 ISA 가입 조건 소득 기준")
- 시의성: 제도 시행일 · 실적 발표 · 정책 변경 직후 검색 증가
- 반복 수요: 연말정산 · 세액공제 · 연금 계좌처럼 매년 돌아오는 주제
- 광고 단가: 금융(대출 · 보험 · 카드) · 법률 · 건강이 높음. 동시에 YMYL 기준이 가장 엄격하고 경쟁 심함. 승인 전에는 근거 확보가 쉬운 정보형 주제 우선
- 시리즈화: 한 사건 · 기업 · 제도를 여러 편으로 나누고 목차로 연결하면 내부 유입 · 체류 증가

## 글 맥락 (독자가 머무는 글)

| code | 원칙 | 적용 |
|---|---|---|
| C1 | 검색 의도 일치 | 검색 질문의 답을 첫 화면에 |
| C2 | 질문 흐름 순서 | 문제 → 핵심 답 → 구체 방법 · 수치 → 단계별 상세 → FAQ |
| C3 | 독자 상황 대입 | 소득 · 금액별 계산 예시 |
| C4 | 왜 지금 | 시점 근거 (발표일 · 시행일) |
| C5 | 표 · 차트 | 비교 수치는 문장보다 표 |
| C6 | 출처 공개 | 공시 · 통계 · 공식 문서 링크, 작성 시점 명시 |
| C7 | 고유 분석 | 상위 검색 결과 요약 이상. 자기 관점 · 경험 |
| C8 | 자동화 공개 | AI · 자동화 사용 시 공개 |

## 블로그 구성

- 필수 페이지: `pages.md`
- 분류: 대분류 5개 안팎 고정 (Blogger 라벨). 글 0 ~ 1편 라벨은 신청 전 정리
- 메뉴: 상단에 대분류 + 소개. 푸터에 문의 · 개인정보처리방침 · 면책
- URL: 짧은 영문 slug (Blogger 는 게시 전 "맞춤 퍼머링크")
- 글마다: 검색 설명(meta description), 이미지 alt, 관련 글 · 시리즈 목차 내부 링크
- Search Console: 속성 등록 · sitemap 제출 · 색인 생성 범위 정기 확인
- 커스텀 도메인: 필수 아님. 연결 시 HTTPS 리디렉션 · Search Console 속성 재등록
