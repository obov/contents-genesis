# ChatGPT 이미지 생성 (재사용 키트)

> 실전 검증 패턴 모음. 프로젝트별 경로(글 폴더, 페르소나 파일, 생성 스크립트)는 각 프로젝트의 채널 스킬에 둔다.
> 브라우저 공통 함정은 `kit-browser-automation`을 먼저 읽는다.

## 원칙

- ego-browser의 사용자 로그인 세션으로 `https://chatgpt.com` 사용. 로그인 필요 시 `task.handOff()` 후 사용자 요청
- 한 작업(글·편)은 TaskSpace 1개, ChatGPT 대화 1개에서 진행 (인물·톤 일관성)
- 파일명·캡션에 AI 생성 표시 (예: `*_ai.png`, 캡션 `AI 생성 이미지`)
- 제품 장면은 실제 사용 방식·크기·질감 기준. 과장된 효과(전후 비교 등) 연출 금지
- 상품 외형(로고, 용기, 색상)은 판매 페이지 이미지를 참조로 첨부. 실제 상품과 다르면 재생성
- 실존 타인의 얼굴·유명인 사용 금지. 인물은 프로젝트가 소유한 페르소나 자료만 사용

## 얼굴 각도·표정 복제 주의

- 증상: 한 대화에서 만든 인물 컷이 전부 같은 얼굴 각도·표정으로 나옴. 첨부한 원본 사진의 포즈를 그대로 복사하는 경향
- 결과: 합성 티가 나서 신뢰도 하락
- 규칙
  - 프롬프트에 "얼굴 **정체성**(이목구비·헤어)만 유지하고 **각도·표정·시선은 원본과 다르게**" 명시
  - 장면마다 각도·표정·시선을 지정하고 한 작업 안에서 겹치지 않게 배분: 정면, 3/4 측면, 옆얼굴, 뒷모습·어깨너머, 손 클로즈업 / 무표정·집중, 큰 웃음, 놀람, 편안함
  - 인물 컷 절반 이상은 얼굴 없는 컷(손·상품 클로즈업, 뒷모습)
  - 옷도 장면마다 다르게 지정
  - 생성 후 **작업 단위로 인물 컷을 나란히 놓고** 중복 검사 (1장씩 보면 못 잡음)

## 캐릭터 시트 (인물 일관성 강화)

- 원본 사진 1장을 계속 첨부하면 원본의 배경·포즈·옷이 복제됨 → 원본은 시트 생성에만 사용
- 시트 구성: 기준 얼굴 1장 + 축별 시트 (헤어 H1~Hn, 표정 E1~En, 각도 A1~An) + 정의 파일(`sheet.json`)
- 장면마다 조합 코드 `H-E-A` (예: `H3-E2-A2`)를 지정하고, 해당 시트 이미지를 첨부
- 한 작업 안에서 같은 A·E 반복 금지, 정면(A1)은 최대 1장
- 결과물 manifest에 조합 코드 기록 → 검수 시 코드대로 나왔는지 대조

## 화면 요소 (2026-09 기준)

- 입력창 `textarea[name="prompt"]`, 첨부 `button[aria-label="파일 등 추가"]`, 전송 `button[aria-label="메시지 보내기"]`
- 로그아웃 상태에서는 이미지 생성·파일 업로드 불가

## 절차

1. 새 대화 → 첨부 버튼으로 업로드 (`page.waitForFileChooser()` 후 `chooser.setFiles([...절대경로])`)
2. 프롬프트 입력·전송. 완료 판정: 이미지 요소 로드 + 응답 중지 버튼 사라짐 (버튼 상태만으로 판단 금지)
3. 저장: 생성 이미지는 `blob:` URL → 페이지 안에서 fetch → base64로 꺼내 파일 저장. 또는 다운로드 버튼 + `waitForEvent("download")`
4. 저장 파일을 열어 확인 (얼굴 일관성, 상품 외형, 손가락·글자 깨짐). 큰 이미지는 `sips -Z 560` 등으로 축소 후 확인
5. `manifest.json`에 파일명, 프롬프트, 참조 파일, 용도 기록

- 1장 약 1분. 세로 4:5 요청 시 약 1122x1402 PNG
- 대기 초과 시 스크린샷으로 거절·되묻기 여부 확인
- 스마트스토어 상품 이미지 참조: `img[alt="대표이미지"]` URL을 `Referer: https://smartstore.naver.com/` 헤더로 curl (page.fetch는 CORS 실패). 실제 형식은 JPEG

## 프롬프트 템플릿

첫 장 (새 대화, 인물·상품 첨부):

```text
이미지 여러 장을 이 대화에서 차례로 만들 거야. 첫 번째 사진의 인물(얼굴·헤어 유지)이 인물, 두 번째 사진의 <제품>(디자인·색상·로고 유지)이 제품이야. 이번 장면: ...
```

다음 장 (같은 대화, 첨부 없이):

```text
다음 장면(같은 인물, 같은 제품): ...
```

상품 단독 컷:

```text
첨부한 상품 사진과 동일한 제품(로고·용기·색상 유지)을 밝은 자연광의 원목 테이블 위에 놓은 라이프스타일 사진. 1:1, 사실적인 스마트폰 촬영 느낌, 텍스트·워터마크 없음.
```

한 번에 1장씩 요청. 수정은 같은 대화에서 차이만 지시 ("인물 유지, 제품 라벨을 참조 사진과 동일하게").
